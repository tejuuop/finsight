# FinSight — Agentic Financial Research & Filing Intelligence

FinSight is a full-stack AI financial research MVP that answers questions over public company SEC 10-K filings using Retrieval-Augmented Generation (RAG), PostgreSQL (`pgvector`), LangGraph conditional routing, deterministic financial calculation tools, and the Gemini API.

> **Disclaimer:** This project is an educational portfolio prototype and does not provide financial or investment advice. Generated responses may contain errors and should always be verified against official SEC filings.
